PROYECTO: CLÍNICA DENTAL SONRISA SANA

Archivos incluidos:
- index.html
- nosotros.html
- servicios.html
- contacto.html
- css/estilos.css
- js/script.js
- img/ (tres imágenes SVG)

CÓMO USAR:
1. Extrae la carpeta del archivo ZIP.
2. Abre la carpeta completa en Visual Studio Code.
3. Abre index.html con Live Server.
4. Revisa los cuatro enlaces del menú y el formulario.

ANTES DE ENTREGAR:
- Cambia los datos de contacto de ejemplo si tu profesor espera datos reales.
- Crea un repositorio en GitHub y sube todos los archivos.
- Realiza al menos dos commits con mensajes descriptivos.
- Valida cada HTML en https://validator.w3.org/
- El formulario es solo estructura HTML y no envía mensajes a un servidor.
